# Open ForgeSight locally

1. Open this folder in PyCharm.
2. Select `.venv/Scripts/python.exe` as the interpreter.
3. Run `run.py`.
4. Open **http://127.0.0.1:8010**.

This prepared local folder contains the fitted model and downloaded dataset in ignored directories. A fresh Git clone does not: follow the [README setup commands](README.md#run-in-pycharm) to regenerate them.

Try **broken large → Run inspection**, compare the original with its heatmap, and record a review. Open **Model performance** to explore threshold tradeoffs and lighting shifts.

This source repository is separate from Relay and EXORA. No external account or paid API is needed.
